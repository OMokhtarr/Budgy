# Store assets

Makes the Google Play graphics in `store/`, using screenshots of the real app filled with demo data.

| Output | Size |
|---|---|
| `store/icon-512.png` | 512×512 app icon, a copy of `public/icons/icon-512.png` (not regenerated by these scripts) |
| `store/<lang>/feature-graphic.png` | 1024×500 |
| `store/<lang>/screenshot-N.png` | 1080×1920, with a caption |

## Regenerate

Run from the project root. Needs Python with the `playwright` package and Microsoft Edge, which the
scripts use instead of a downloaded browser.

```bash
npx vite --port 5175 --host 127.0.0.1          # in one terminal, leave it running
python scripts/store-assets/capture.py          # in a second terminal: raw shots → scripts/store-assets/raw/
node scripts/store-assets/frame.mjs scripts/store-assets/raw store public/icon.png   # captions → store/
```

Delete `store/en` and `store/ar` first if a language now has fewer screenshots, or the old extra
files stay behind.

## Files

- `demo_data.py`: the demo backup (accounts, budgets, six months of transactions), in English and
  Arabic. The browser clock is fixed at 26 Nov 2026 (`TODAY` in `recon.py`), so the month looks full.
- `recon.py`: loads the demo data into the dev server through the app's own `importBackup`.
- `capture.py`: takes the raw 1080×2160 screenshots for each language.
- `frame.mjs`: adds the captions and draws the feature graphic. Captions and the screenshot order
  are in `CAPTIONS`.
